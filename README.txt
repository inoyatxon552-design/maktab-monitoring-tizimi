MONITORING TIZIMI — YANGILANGAN DEMO

1. ZIP faylni oching va index.html faylini Chrome/Edge brauzerida oching.
2. Admin kirishi: dastlabki parol admin123.
3. Admin panelida o'quvchilarni Excel/CSV orqali import qiling yoki qo'lda qo'shing.
4. Har bir fan uchun TXT test bankini import qiling.
5. Sinf + chorak + blokni tanlang, 3 ta fan biriktiring va shu guruh uchun alohida test kodini belgilang.
6. O'quvchi panelida sinfi, F.I.SH., chorak va blokni tanlab, aynan shu guruh kodini kiritadi.
7. Natijalar admin panelidagi “Tahlil hisobotlari” bo'limida saqlanadi. CSV fayl Excel'da ochiladi.

TEST TXT FORMATI:
# 2 + 2 nechaga teng?
- 3
- 4*
- 5
- 6

Savol # bilan, javob variantlari - bilan boshlanadi. To'g'ri javob oxiriga * qo'yiladi.
Har bir fan bankida kamida 15 ta savol bo'lishi kerak; 50 ta tavsiya etiladi.
Har bir test 3 fan x 15 savol = 45 savol, 90 daqiqa.
Yakunlash tugmasi barcha 45 savolga javob belgilanganidan keyin faollashadi.

MUHIM: Bu demo ma'lumotlarni faqat shu brauzer/qurilmadagi localStorage'da saqlaydi. Turli kompyuterlardan natijalarni yagona admin paneliga yuborish uchun server va umumiy ma'lumotlar bazasi kerak. DOCX import bevosita yo'q; DOCX matnini TXT qilib saqlab import qiling.
